## The posting

An intermediate developer role on an AWS IoT and smart-metering platform supporting more than 500,000 meters across more than 3,500 buildings. The posting asks for three to five years of professional experience and covers backend services, APIs, integrations, cross-stack troubleshooting, architectural discussions, technical-debt work, real-time monitoring, communication protocols, data automation, and documentation.

### Advertised responsibilities

- Develop and maintain applications supporting an AWS IoT cloud platform and communications layer.
- Build backend services, APIs, and integrations for device management, data acquisition, reporting, and building automation.
- Work across Embedded Systems, Cloud, Data, and Operations.
- Troubleshoot issues across the stack and contribute to internal tools and processes.
- Participate in architectural discussions and implement scalable solutions.
- Identify and remediate technical debt while balancing product-delivery timelines.
- Develop features for smart metering, real-time monitoring, communication protocols, and data automation.
- Document systems, workflows, and code.

### Advertised requirements

- Three to five years of professional software-development experience.
- TypeScript/JavaScript proficiency plus experience in Python or PHP.
- API, SQL/NoSQL, cloud-application, and AWS experience.
- Docker is required; microservices and CI/CD are assets.
- Professional experience with agentic AI / AI-assisted development tools such as Claude Code is required.
- IoT, distributed-systems, and Go experience are assets.
- Ability to work in a fast-paced, evolving, build-as-you-go environment.
