## The posting

A senior full-stack role covering C#/.NET, React, SQL Server, Azure, Azure Functions, Azure DevOps, AI-assisted development, production troubleshooting and client-facing technical guidance. Cognizant asks for six-plus years of software-development experience and expects the developer to influence technical decisions, guide client managers and technical teams, and resolve critical issues that can span both applications and infrastructure. The listed base range is CAD $60,000–$95,000.

### Advertised responsibilities

- Design, develop and maintain secure, high-performing full-stack applications.
- Work across C#/.NET, React, SQL Server and Microsoft Azure.
- Collaborate with business stakeholders and clients to recommend technical solutions.
- Guide client managers and technical teams on application design and technology choices.
- Use GitHub Copilot and other AI-assisted development tools.
- Implement chat interfaces and lightweight automation agents.
- Analyze logs, monitor performance and troubleshoot production failures.
- Resolve critical issues across application and infrastructure boundaries.

### Advertised requirements

- 6+ years of overall software-development experience.
- Strong C#, .NET Framework and .NET Core experience.
- Hands-on React experience.
- SQL Server in on-premises and Azure environments.
- Azure Functions and Azure DevOps experience.
- Hands-on GitHub Copilot use for coding, testing, debugging or troubleshooting.
- Production monitoring/debugging experience and strong stakeholder communication.
