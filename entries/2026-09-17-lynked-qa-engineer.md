## The posting

A QA engineering role across LYNKED's IoT platform, cloud services and smart-metering ecosystem. The engineer designs manual and automated tests for web applications, APIs and backend services, builds and maintains automation suites, contributes test gates to CI/CD, validates data across device communication and acquisition pipelines, and uses AI-assisted/agentic tooling for test generation and defect triage. The posting requires three years of software-testing experience and starts at CAD $50,000.

### Advertised responsibilities

- Design and execute manual and automated test plans, cases and scripts.
- Test web applications, APIs and backend services.
- Build and maintain automated test suites.
- Perform functional, integration, regression, performance and exploratory testing.
- Work with developers, embedded engineers and cloud teams.
- Contribute automated tests and quality gates to CI/CD pipelines.
- Validate data integrity across device communication, acquisition pipelines and reporting outputs.
- Use AI tools and agentic workflows for test generation, coverage analysis and defect triage.

### Advertised requirements

- 3 years of software-testing experience required.
- Ability to commute or relocate to London, Ontario.
- The application asks candidates to describe a test-automation framework they built or significantly contributed to, including the programming language, design and biggest technical challenge.
